## TDD: 为 6 个列表页增加搜索功能

用户反馈多个列表页缺少搜索：设备模板、配件型号、库存流水、部门管理、设备分类、配件分类。

### 方案（页面层过滤，统一体验）
- 新增 `src/lib/list-search.ts`：
  - `filterItemsByText(items, query, getText)` — 单/多字段文本过滤（不区分大小写），query 为空原样返回。
  - `filterTreeByText(nodes, query, getName?)` — 树形（扁平 parentId）过滤，命中节点的祖先一并保留，保证 TreeTable 树结构完整。
- 新增 `src/components/ui/list-search-input.tsx` — 受控搜索框（搜索图标 + 清除按钮），风格与 DataTable 内置搜索框一致。
- 六个页面均改为「页面内 state 搜索 → useMemo 过滤 → 传给表格组件」：
  - `templates/template-list-client.tsx`：按 名称 + 分类名 过滤（DataTable）。
  - `components/models/models-client.tsx`：按 名称 + 品牌 + 分类名 过滤（DataTable）。
  - `components/stock/stock-log-client.tsx`：按 配件型号 + 类型中文标签 + 操作员 + 备注 过滤（DataTable）。
  - `settings/departments/departments-client.tsx`：按 名称 过滤（手动分页，过滤后再 slice，搜索时重置 currentPage）。
  - `settings/asset-categories/asset-categories-client.tsx` + `component-categories-client.tsx`：按 名称 过滤（TreeTable，用 filterTreeByText 保留祖先）。

## TDD: DataTable 表格样式专项优化（第 4 类）

用户追问"还有可优化的点吗，比如表格样式"，经核查代码给出诊断并实现：

### 诊断（关键发现）
- **列宽配置形同虚设**：列定义里写了 `size`/`minSize`(select 40 / config 180 / actions 200)，但 `data-table.tsx` 渲染时从未把 `column.getSize()` 接到 `style.width`，浏览器走 `table-auto` 自由分配 → 这是"布局怪"的真正根因。
- **hover 排序箭头是死的**：上一轮日志写"表头加 group 让箭头 hover 可见"，但核查代码发现 header `<TableRow>` 实际**没有 `group` 类**，箭头 `group-hover:opacity-50` 永远不可见（上轮该改动未真正生效，本轮补上）。
- 长文本不截断(配置列 ellipsis 因无 max-width 不触发)、数值列未右对齐、表头 `font-normal` 与基础 TableHead `font-medium` 不一致、表头不吸顶、斑马纹偏重。

### 实现（`src/components/features/data-table.tsx`）
- 新增 `getColStyle(column)`：把 `size`(≠TanStack 默认 150 才应用,避免把未设列强制 150px) 与 `maxSize`(<100000 才应用) 映射成 `style.width/maxWidth`，同时作用于 th 与 td → 列宽真正生效。
- 表头 `<TableRow>` 补 `group` + `sticky top-0 z-10` + 背景实色 `bg-muted`(避免吸顶时内容穿透)；外层容器 `overflow-hidden`→`overflow-auto max-h-[70vh]`(sticky 生效前提)。
- 表头 `font-normal`→`font-medium`(与基础 TableHead 对齐)；排序按钮右对齐列加 `justify-end`。
- 斑马纹 `/15`→`/10`，选中行 `/8`→`/10`，强化区分。
- 配置列(`asset-list-client`)加 `maxSize:240` 配合已有 `whitespace-nowrap overflow-hidden text-ellipsis` → 省略号真正生效。
- 三页数值列右对齐：`templates` 配件数量、`models` 库存数量、`stock-log` 数量 均加 `meta:{align:'right'}`。

### 测试（TDD 红→绿）
- 新增 `tests/data-table-style.test.tsx`(7)：列宽 style 生效(显式/未声明区分)、group+sticky+实色、外层 overflow-auto+max-h、font-medium、数值 text-right、斑马纹 `/10`。
- 运行受影响的 7 个既有前端测试(asset-delete-vs-scrap / templates·models·stock-log 筛选与重置)共 24 全绿；`npx tsc --noEmit` 干净。
- 排错：① TanStack 把未设列的 size 默认填成 150 → `getColStyle` 改用"==默认 150 视为未设置"跳过；② tsc 报 `Column` 未导入 + 测试 `Element.style` → 补 `Column` 导入、测试里 `querySelector` 断言 `HTMLElement`。

### 验证结论
- 表格布局、吸顶、排序提示、可读性(右对齐/截断)、表头一致性全面到位。
- 服务器生效：`git pull` + `npm run docker:update`(仅代码) 或 `npm run docker:deploy`(含迁移)。改动**尚未 git 提交**。
